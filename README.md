# ME Cross Cable

1ブロック内で3本のME回線を独立して通すAE2アドオン。
Forge 1.20.1 / Java 17 / AE2 15.4.10以上。ACOは不要です。

## ケーブル

| アイテム | ID | 標準設定での容量 |
| --- | --- | --- |
| MEクロスケーブル | `me_cross_cable:cross_cable` | 各回線8チャンネル |
| MEスマートクロスケーブル | `me_cross_cable:smart_cross_cable` | 各回線8チャンネル・使用数表示 |
| ME高密度スマートクロスケーブル | `me_cross_cable:dense_smart_cross_cable` | 各回線32チャンネル・使用数表示 |

AE2のチャンネル倍率・無制限設定を維持します。各回線の容量を合算して1本へ流す
機能や、在庫・電力を別回線と共有する機能はありません。外部の配線で回線同士を
つなげば、その外部配線を通じて同じネットワークになるのは通常のAE2と同じです。

## 配線と設定

- 初期状態は、回線1が東西、回線2が上下、回線3が南北を接続します。
- 素手で右クリックして設定画面を開き、つなぐ2面を選択します。曲がる接続にもできます。
- 最初に選んだ面の回線を使用します。押し出された端は相手の回線へ移り、常に2面×3回線を保ちます。
- ME通信は双方向です。搬入専用・搬出専用を設定する機能ではありません。
- 白い筐体の6面に接続口があります。端子は実際につながっているAE2ケーブルの色を表示し、回線ごとの固定色はありません。
- 通常・スマートの筐体幅は9px、高密度は13px。AE2の直線スマートケーブル6px・高密度10pxより全幅で3px大きくしています。
- 各接続口の1px幅の発光リングは、実際に接続しているケーブルの色で発光します。未接続は消灯。回線識別のリングと8／32チャンネル表示は別で、接続色の表示はチャンネルを消費しません。
- 接続している面だけ、AE2接続部と同じ4px／8pxの短い接続部をブロック境界まで表示します。
- 染料でクリックした面の回線をAE2の色へ変更します。スニーク＋素手の右クリックでフルーシュへ戻せます。
- 両端の接続色が異なる場合も、各端子はそれぞれの接続色を表示します。未接続・未染色の端子は金属色です。
- 接続先の色を読み取る処理は表示専用です。ノード自体の染色や接続条件を自動変更しません。
- スマート系は各接続口に、その面に割り当てた回線の使用チャンネルを表示します。正確な使用数・容量は設定画面にも表示します。
- 接続面・染色はワールド保存と通常の回収アイテムに保持します。

作成には対応するAE2ケーブル3個とクォーツガラス1個を使用します。
専用クリエイティブタブもあります。サーバーとクライアントの両方へ同じJARを導入します。

## 実装範囲

AE2公開APIによる3個の独立GridNodeを使用します。Mixin、独自の転送処理、
常時実行するBlockEntity ticker、ワールド走査は追加しません。
静的なモデルはベイク済み、点灯部分だけをクライアントで描画し、状態同期はイベント駆動です。
外部ケーブルのモデルやテクスチャは上書きしません。
オリジナル16x16テクスチャとモデルはソース内のアセット生成器から生成します。

## 開発

```powershell
.\gradlew.bat build
```

AE2の公式配布JARをローカルで使う場合は、JARのディレクトリを
`-Pae2LocalDir=<directory>`で指定します。ビルド時のAE2固定版は15.4.11です。
AE2が要求するGuideMEは開発用の実行依存として設定されています。

モデル・16x16テクスチャ・翻訳・レシピは同梱済みです。
アセット生成器を変更した場合は `.\gradlew.bat generateAssets` で再生成します。

配布物は`build/libs/me-cross-cable-forge-1.20.1-<version>.jar`です。
`-sources.jar`は導入しません。NeoForge版はまだ実装していません。

初期版はAlphaです。検証済み範囲と未検証項目は[検証記録](docs/VALIDATION.md)を参照してください。
